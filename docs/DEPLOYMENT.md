# Deployment Guide

Step-by-step guide to deploying the Adaptive Learning Agent.

## Prerequisites

- AWS account (with ECR, ECS, and IAM permissions)
- Docker Desktop
- AWS CLI v2 configured (`aws configure`)
- Groq API key
- Tavily API key (optional, for web search)

## Environment Variables

The following environment variables must be set:

```bash
APP_ENV=production
PORT=8000
LOG_LEVEL=INFO
DATABASE_URL=sqlite+aiosqlite:///./data/adaptive_learning.db

# LLM
GROQ_API_KEY=gsk_...
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_MODEL=qwen/qwen3.8-27b
GROQ_MIN_REQUEST_INTERVAL=2.5

# Web search (optional)
TAVILY_API_KEY=tvly-...
Step-by-Step Deployment
1. Build the Docker image locally
bash
docker build -t adaptive-learning-agent:latest .
Expected time: 2-5 minutes (first build).

2. Create the ECR repository
bash
aws ecr create-repository \
    --repository-name adaptive-learning-agent \
    --region us-east-1
3. Authenticate Docker to ECR
bash
aws ecr get-login-password --region us-east-1 | \
    docker login --username AWS --password-stdin \
    <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com
Expected output: Login Succeeded

4. Tag the image
bash
docker tag adaptive-learning-agent:latest \
    <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/adaptive-learning-agent:latest
5. Push the image
bash
docker push \
    <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/adaptive-learning-agent:latest
Expected time: 1-3 minutes.

6. Create the ECS service
Use the AWS Console:

Navigate to ECS → Express Mode → Create

Fill in:

Image URI: <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/adaptive-learning-agent:latest

Container port: 8000

Health check path: /api/v1/health

Service name: adaptive-learning-agent

Environment variables: (see above)

Click Create

Expected time: 5-6 minutes for provisioning.

7. Access the application
Once deployed, the application is available at the URL shown in the
ECS Console:

text
https://<auto-generated>.ecs.us-east-1.on.aws
Stopping the Service (to save costs)
The service costs ~$20/month when running 24/7. To stop:

bash
aws ecs update-service \
    --cluster adaptive-learning-agent \
    --service adaptive-learning-agent \
    --desired-count 0 \
    --region us-east-1
Costs while stopped: ~$6/month (ALB remains).

Restarting the Service
bash
aws ecs update-service \
    --cluster adaptive-learning-agent \
    --service adaptive-learning-agent \
    --desired-count 1 \
    --region us-east-1
Expected time: 1-2 minutes.

Updating the Application
After making code changes:

bash
# 1. Rebuild
docker build -t adaptive-learning-agent:latest .

# 2. Tag
docker tag adaptive-learning-agent:latest \
    <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/adaptive-learning-agent:latest

# 3. Push
docker push \
    <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/adaptive-learning-agent:latest

# 4. Force new deployment
aws ecs update-service \
    --cluster adaptive-learning-agent \
    --service adaptive-learning-agent \
    --force-new-deployment \
    --region us-east-1
Monitoring
Logs: CloudWatch → /ecs/adaptive-learning-agent

Metrics: ECS Console → Service → Metrics

Health endpoint: <URL>/api/v1/health

Troubleshooting
Service fails to start
Check CloudWatch logs:

bash
aws logs tail /ecs/adaptive-learning-agent --follow --region us-east-1
Health check fails
Verify the health endpoint works locally:

bash
curl http://localhost:8000/api/v1/health
503 from ALB
Confirm the task is running (aws ecs list-tasks)

Confirm the target group is healthy

Rate limits from Groq
Increase GROQ_MIN_REQUEST_INTERVAL in the service environment.

Full Cleanup
To remove all AWS resources:

bash
# ECS service
aws ecs delete-service --cluster adaptive-learning-agent \
    --service adaptive-learning-agent --force --region us-east-1

# ECS cluster
aws ecs delete-cluster --cluster adaptive-learning-agent --region us-east-1

# ECR
aws ecr delete-repository --repository-name adaptive-learning-agent \
    --force --region us-east-1
Warning: This deletes all data.
